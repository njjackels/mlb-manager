MLB Dynasty Team Manager
Version 1.00 Stable

HOW TO OPEN
1. Keep every file in this folder together.
2. Double-click index.html.
3. The app saves changes in your browser automatically.

VERSION 1.00 CHANGES
- Added a Backup and Restore page.
- Added Export Data for players, roster assignments, trades, transactions, highlights, and settings.
- Added Import Data with file validation and a replacement summary.
- Added a protected Reset App process that requires typing RESET.
- Added storage totals and app-data counts.
- Improved keyboard focus visibility and form validation styling.
- Improved navigation, forms, toolbars, and data controls on smaller screens.
- Updated the app title and header to Version 1.00 Stable.

BACKUP RECOMMENDATION
Export a backup after major roster or trade changes. The downloaded JSON file can restore the app in the same browser or move the data to another computer.

FILES
- index.html: App structure and dialogs
- app.js: App features, storage, backup, restore, and validation
- style.css: Layout and visual design
- data.js: Original workbook data
- field.jpg: Field Map background
